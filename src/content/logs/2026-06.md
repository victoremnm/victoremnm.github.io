### 2026-06-05
- **Ship:** Migrated a backend service off a deprecated client SDK internals pattern onto the maintained one, ahead of the old path being dropped entirely.
- **Learn:** Deprecation warnings you can safely ignore for months are exactly the ones that turn into a forced same-day migration later — cheaper to do it on your own schedule.

### 2026-06-08
- **Ship:** Increased stream retention on a chain-data ingestion service and added compression, after noticing a downstream consumer needed a longer replay window than the default gave it.
- **Learn:** Retention windows tend to get set once at launch and never revisited — worth treating as a parameter to tune as consumers change, not a fixed constant.

### 2026-06-17
- **Ship:** Unified a scattered set of per-repo agent-instruction files into a single canonical spec, since I was maintaining near-duplicate copies across several personal projects.
- **Learn:** The moment you have the same conventions doc drifting slightly across repos, the drift itself becomes the bug — better to have one source and reference it than N almost-identical copies.
