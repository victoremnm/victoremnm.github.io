### 2026-07-11
- **Ship:** Shipped multihop routing support for an additional DEX integration in the trade execution service, plus a fee-accounting fix (price impact was being double-counted against fees in one code path).
- **Learn:** Fee math bugs are the ones worth the most paranoia in a trading system — a routing bug fails loudly, a fee bug just quietly costs money until someone notices the numbers don't reconcile.

### 2026-07-13
- **Ship:** Removed a derived stats column from the Magic tournament tool's standings view after finding the derivation was silently wrong for some match records, in favor of showing only what's directly ingested.
- **Learn:** A computed field that's "usually right" is worse than no field at all — it took longer to notice the derivation bug than it would have taken to just not compute the value client-side in the first place.

### 2026-07-22
- **Ship:** Wrote down explicit conventions for multiple AI coding agents (Claude, Gemini, and others) working the same repo concurrently — PR-claiming rules, co-authorship tagging, a "blocked" protocol so agents don't collide on the same file.
- **Learn:** Multi-agent coordination has the same failure modes as multi-human coordination (double work, silent overwrites) — the fix is the same too: an explicit, boring protocol beats hoping everyone naturally avoids collisions.
