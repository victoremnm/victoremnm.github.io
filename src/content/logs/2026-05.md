### 2026-05-13
- **Ship:** Built an automated slide-deck pipeline — live data from an analytics API straight into a rendered deck (Marp theme + a Python generator for an editable export), rather than hand-updating slides every time the underlying numbers moved.
- **Learn:** Once the data source is live and queryable, most of the "deck maintenance" problem disappears — the remaining work is presentation, not re-fetching numbers.

### 2026-05-14
- **Ship:** Shipped RSI-based filtering for an internal monitoring service, matching TradingView's exact calculation (Wilder's smoothing, no gap-filling, a proper warm-up window) instead of a naive moving-average approximation.
- **Learn:** "Matches a well-known charting tool's numbers" is a much better spec than "compute RSI" — indicator math has enough implementation variants that matching a reference implementation is the only way to avoid a stream of "why doesn't this match what I see elsewhere" bug reports.

### 2026-05-27
- **Ship:** Migrated the nonprofit's admin database schema toward 3NF and moved auth onto Auth0, including infra-as-code for user config so it's not a manual console step anymore.
- **Learn:** Untangling a schema that grew organically (duplicate fact tables, a legacy "data warehouse" schema shadowing the real one) is mostly archaeology — the actual migration is the easy part once you know what's real.
